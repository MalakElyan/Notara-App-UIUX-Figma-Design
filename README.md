**Notara** is an advanced, AI-driven mobile productivity platform designed in **Figma** to unify and simplify digital workflows for students, educators, and professionals. It integrates **AI document synthesis**, **real-time OCR handwriting conversion**, and **contextual audio anchoring** into an immersive, distraction-free workspace.

## 💡 Design Thinking Framework

This project was built following the 5 human-centered stages of the **Design Thinking Methodology**:

| Stage | Focus & Execution |
| :--- | :--- |
| **1. Empathize** | Conducted qualitative user interviews and user research with students, educators, and researchers. |
| **2. Define** | Identified core productivity pain points, including app fragmentation, digital fatigue, and study distractions. |
| **3. Ideate** | Brainstormed AI-driven solutions: **AI Summarization**, **Real-time OCR**, **Contextual Audio Anchoring**, and **Pomodoro Mode**. |
| **4. Prototype** | Designed Low-Fi wireframes and developed an interactive High-Fi prototype using Figma. |
| **5. Test** | Validated user flows, edge-case scenarios, and overall interface usability through practical feedback. |

## ✨ Cutting-Edge Features & UI Highlights
- 🧠 **AI-Driven Document Synthesis:** Smart UI flows for automatic summarization and document insights.
- ✍️ **Real-Time OCR Conversion:** Seamless interface for converting handwritten notes into editable digital text.
- 🎙️ **Contextual Audio Anchoring:** Voice recording linked directly to specific notes and document timestamps.
- ⏱️ **Immersive Study Mode (Pomodoro):** Gamified focus timer and analytics dashboard designed to eliminate digital fatigue.
- 📋 **Integrated Task & Resource Management:** Centralized hub for managing academic schedules and task lists.
